A matrix completion conjecture

Let A be a finite rectangular matrix whose entries are 0, 1, or ?. A question mark denotes a blank. A completion replaces every blank by either 0 or 1 and leaves every originally specified bit unchanged.

Rows and columns retain their given order. A forbidden diagonal rectangle consists of rows i < j and columns p < q with

A[i,p] = 1, A[i,q] = 0,
A[j,p] = 0, A[j,q] = 1.

The corresponding pattern is

1 0
0 1

The chosen rows and columns need not be consecutive. Call a completed matrix diagonal-rectangle-free if it contains no such four entries.

Here are two examples of the unrestricted completion question. The partial matrix

1 ?
? 1

has the diagonal-rectangle-free completion

1 1
0 1

whereas the following partial matrix has no diagonal-rectangle-free completion:

1 ? 0
? 0 1
0 1 0

To define an initial local obstruction, consider a blank together with three other corners that are already specified. If assigning a bit to that blank completes a forbidden diagonal rectangle, that bit is locally forbidden there. For example,

1 0
? 1

forces its blank to be 1.

Call the original partial matrix viable when both of these conditions hold:
1. No forbidden rectangle is already present using four specified entries.
2. At every blank, both 0 and 1 are individually locally allowed: assigning either bit to that one blank, while leaving all other blanks unassigned, creates no forbidden rectangle with three originally specified corners.

Prove or disprove the conjecture that every viable partial matrix has a diagonal-rectangle-free completion. The claim ranges over all finite rectangular dimensions. If it is true, give a rigorous finite proof. If it is false, provide an explicit finite partial matrix, verify its viability, and rigorously establish that none of its completions is diagonal-rectangle-free.

An unsupported report from a search or solver does not settle the question.
