# Matrix filling prompt set, v1

These ten standalone prompts restate Sections 1–3 of the Matrix Filling Game mathematical poster. They ask the same proof-or-counterexample question, use the same examples, and include the same initial local viability conditions. Only wording, notation, and presentation vary. Later poster sections and their answers are omitted.

The filename identifies the variant; no variant ID or benchmark label is included in the text copied into a model. Record that filename together with the model/version and run settings when comparing results. `manifest.json` records the source revision and each prompt hash. Change the set version when deliberately changing the mathematical task or output requirements.

The existing big blue button opens one text file in a new tab. It draws from a shuffled bag: each browser receives all ten before the next cycle, and adjacent cycles do not repeat the same variant back-to-back. The state stays in browser storage. If storage is unavailable, the cycle is maintained for that page visit. Different visitors or browsers may receive the same variant; ten versions do not guarantee global uniqueness. Opening the context menu counts as requesting a variant.

A versioned URL is refreshed on every activation to avoid old cached text. The original `the-big-blue-button.txt` address remains an alias containing variant 01.
