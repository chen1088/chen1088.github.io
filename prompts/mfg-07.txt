Here is a matrix completion question. Start with any finite rectangular array containing 0s, 1s, and blanks written as ?. You may replace each ? by 0 or 1, but may not alter a prescribed entry.

The arrangement to avoid is

1 0
0 1

at the intersections of two rows and two columns. More explicitly, for row indices r < s and column indices c < d, the four values must not be 1, 0, 0, 1 in the positions (r,c), (r,d), (s,c), (s,d), respectively. This restriction applies even when the selected rows or columns are separated by other rows or columns. Their given order must be respected.

For example, a successful filling is

1 ?          1 1
? 1    ->    0 1

whereas the following array cannot be filled successfully:

1 ? 0
? 0 1
0 1 0

There can be an immediate constraint on an individual blank. In

1 0
? 1

the blank has to be 1: choosing 0 completes the prohibited arrangement.

Now impose two starting conditions. First, no prohibited rectangle is already specified entirely by given bits. Second, inspect any blank by itself: assigning it 0 is initially legal, and assigning it 1 is initially legal. In each inspection all the other blanks remain unfilled. A choice is initially illegal exactly when it creates a prohibited rectangle with three other already prescribed corners. Call an array satisfying these two conditions viable.

Is every viable array guaranteed to admit a successful complete filling? Prove or disprove this statement for arbitrary finite numbers of rows and columns.

A positive answer requires a rigorous finite proof for all sizes. A negative answer requires an explicit finite partial array, a verification of its starting conditions, and a rigorous demonstration that every complete filling contains a prohibited rectangle. A claimed computational outcome without justification does not settle the question.
