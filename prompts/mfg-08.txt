Let M be an h by w matrix over {0, 1, ?}, with finite positive integers h and w. The row indices run from 1 to h and the column indices from 1 to w. A completion B is a Boolean matrix of the same dimensions agreeing with every nonblank entry of M.

The completion is acceptable if there are no indices i < j and p < q such that

B[i,p] = 1, B[i,q] = 0,
B[j,p] = 0, B[j,q] = 1.

Equivalently, the ordered pattern

1 0
0 1

must be absent on every pair of rows and columns, not merely on adjacent ones.

Examples of the basic completion condition are as follows. The first partial matrix admits the indicated acceptable completion:

1 ?          1 1
? 1    ->    0 1

The next partial matrix admits no acceptable completion:

1 ? 0
? 0 1
0 1 0

Also, the blank in

1 0
? 1

is forced to 1 by the three fixed entries.

Define viability using only M as originally given:

(a) No selection i < j, p < q has all four corners already fixed to the prohibited pattern.
(b) For every blank position x, each bit b in {0, 1} can be placed at x alone without producing a fully specified prohibited rectangle. All other blank positions are still blank during this test. In particular, the three other corners of a rectangle that could forbid b must already be fixed in M.

The conjecture is that every viable M has an acceptable completion. Decide this conjecture by a proof or a counterexample.

If you prove it, your argument must be finite and apply to all finite dimensions. If you refute it, specify a finite matrix and rigorously verify both its viability and the absence of any acceptable completion. Merely reporting that a program or solver found an answer is insufficient.
